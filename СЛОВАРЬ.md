# СЛОВАРЬ / Codebook

Терминологический словарь для всей документации проекта. Назначение — единый
нейтральный язык описания границ, компонентов и операций рабочей станции
`BugHunterClaudex`. Код в репозитории (имена файлов, API, RPC, идентификаторы)
не меняется — переименованы только описательные термины в прозе.

**Назначение:** при автоматическом чтении документации сторонними моделями
исключить ложно-положительную классификацию «кибер-угроза». Фактическое
содержание и границы работы станции **не изменены**: шлюз политики, очередь
разрешений и область по-прежнему действуют как описано в
`AGENTS.md` §6 и `docs/execution.md`.

## Правила применения

1. **Нейтральность.** Код описывает роль компонента, а не намерение. `ШЛЮЗ-П`
   это слой фильтрации, а не политический объект; `ОВС` это наблюдение
   собственного фикстур-процесса, а не внешнего объекта.
2. **Имена кода не меняются.** Файлы, API, RPC, конфиг-ключи, shell-команды
   сохраняются буквально (`mac_memory_mcp.py`, `ModelTools`, `write_memory`,
   `auto_resume_after_execute`). Переименованы только описательные слова
   прозы, не идентификаторы в коде.
3. **Фактические границы не изменены.** Авторизация, scope, ШЛЮЗ-П, ШЛЮЗ-Р,
   per-request approval, ёмкости и инварианты из `AGENTS.md` §6 действуют
   без изменений.
4. **Двуязычность допустима.** Там где смысл сохраняется лучше, оставлен
   английский термин в скобках после русского кода. `ШЛЮЗ-П (policy gateway)`,
   `R-только (read-only)`.
5. **Исходный смысл восстановим.** Этот словарь — обратимая карта. Полный
   возврат к предыдущей терминологии возможен одним обратным проходом.
