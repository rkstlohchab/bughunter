# Workbench design

A desktop investigation workspace, built around a persistent project context and a split list/detail surface. Request bodies, proposed changes, approvals, and source evidence are the visual anchors. Empty workspaces guide the user to import resources or explicitly open the disposable lab; no fabricated activity is displayed.

Palette: deep harbor #152636; canvas #f2f5f8; paper #ffffff; ink #203248; ocean #237495; evidence teal #148475. Warning and error colors have explicit status text. Dark mode uses the same hierarchy with blue-gray surfaces. System humanist sans typography for navigation and prose; SF Mono/Menlo for HTTP and code. Compact rows, generous evidence readers, one rounded enclosing work surface rather than a grid of metrics. All controls keyboard accessible and reduced motion respected.

The first skill search suggested marketing sections and monochrome labels. Those were rejected for this task: the product is a working desktop tool, with project scope, live run status, source citations, and a separate очередь-Р. There is no marketing hero or invented security score.
